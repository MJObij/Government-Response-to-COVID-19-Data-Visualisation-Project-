# Government-Response-to-COVID-19-Data-Visualisation-Project

## Overview

This project visualises global government responses to the COVID-19 pandemic using Tableau. It presents an analytical view of the measures undertaken across different regions, how these policies evolved over time, and their impact on recovery rates and case statistics. The visualisation synthesises complex data into an engaging and accessible poster format for both academic and public audiences.

## Tools Used

The following tools were employed to build this project:

**Tableau Prep** – Used to clean, reshape and prepare the raw data for analysis  
**Tableau Desktop** – Used to create the visual diagrams  
**Canva** – Used to design supplementary graphics and compose the final infographic poster

## Key Highlights

The final poster visual includes:

- A global map of active cases and region-specific statistics  
- Comparative analysis of health and social policy measures across 190+ countries  
- A breakdown of recovery rates and vaccine distribution efforts  
- Timelines of hospital admissions and policy effectiveness  
- A summary of recommendations for future pandemic preparedness

## Purpose

The aim of this project is to provide a visual narrative of the COVID-19 policy landscape, showcasing both challenges and effective strategies. It is intended as a resource for researchers, public health professionals, policy analysts and the general public seeking to understand the global response to the pandemic through data visualisation.
